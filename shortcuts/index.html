截屏搜题 · 快捷指令

在任何 App 里截屏 → 自动打开搜题平台 → 识别并显示答案
⬇ 下载「截屏搜题」（App 内识别） ⬇ 下载「截屏提取文字搜题」（系统 OCR 更准） 手动创建（不下载）
🎯 推荐用绿色按钮的「截屏提取文字搜题」：它使用 iOS 系统自带的"实况文本"OCR 引擎（和相册/相机里"拷贝文本"同一套，识别率最高、支持离线）， 把截屏里的文字提取出来 → 复制到剪贴板 → 打开搜题平台 → 自动粘贴搜索。对红色背景等难题识别比 App 内 OCR 更稳。
📱 iOS 17 / 18 新系统说明：系统已取消"允许不受信任的快捷指令"开关，但导入共享快捷指令默认允许，直接按下面步骤添加即可，无需任何设置。

方式一：用文件导入（推荐，最快）

1
点上面绿色按钮下载「截屏提取文字搜题」.shortcut（在 Safari 里打开本页）
2
下载完成后，点击下载的文件，在弹窗里选 「快捷指令」 App
3
快捷指令 App 会显示预览（截屏 + 提取文本 + 复制到剪贴板 + 打开URL）→ 滑到底部点 「添加快捷指令」
4
完成！找到「截屏提取文字搜题」点一下即可测试（先随便截个屏）
⚠️ 若提示"此快捷指令无法打开/已损坏"（旧格式被 iOS 18 拒收）：直接看下方方式二手动创建，5 分钟搞定，效果完全一样。

方式二：手动创建（iOS 18 最稳，系统 OCR 版）

1
打开 「快捷指令」 App → 右上角 「+」 新建
2
点底部「添加操作」 → 搜索 「截屏」 → 点选 「截屏」(Take Screenshot)
3
再点「添加操作」 → 搜索 「从图像中提取文本」 → 点选 「从图像中提取文本」(Extract Text from Image)（系统实况文本 OCR，识别率最高）
4
再点「添加操作」 → 搜索 「拷贝到剪贴板」 → 点选 「拷贝到剪贴板」(Copy to Clipboard)
5
再点「添加操作」 → 搜索 「打开 URL」 → URL 粘贴：
searchbank://fab-clipboard
6
点右上角「完成」 → 重命名为 「截屏提取文字搜题」
7
测试：先随便截个屏，点「截屏提取文字搜题」→ 自动提取文字 → 跳到搜题平台 → 自动粘贴搜索 → 弹答案卡
✅ 想要"敲两下背面就全自动"：设置 → 辅助功能 → 触控 → 背面轻点 → 选「双击」→ 滑到最下选 「截屏提取文字搜题」。
以后做题时敲两下手机背面 → 自动截屏 → 自动识别 → 自动搜题，全程零手动。

方式三：分享给朋友（iCloud 链接）

1
在「快捷指令」列表长按要分享的快捷指令 → 点「分享」
2
选 「拷贝 iCloud 链接」（或拷贝链接）——得到 https://www.icloud.com/shortcuts/xxxx
3
把这个链接发给朋友 / 存到自己备忘录；对方在 iPhone 上点开 → 「添加快捷指令」即可，换手机也靠这个链接恢复

⚡ 重点：全自动"敲两下截屏搜题"怎么配

1
确认快捷指令动作完整：「截屏提取文字搜题」应有四个动作：① 截屏 ② 从图像中提取文本 ③ 拷贝到剪贴板 ④ 打开 URL（searchbank://fab-clipboard）。缺哪个补哪个。
2
绑定背面轻点：设置 → 辅助功能 → 触控 → 背面轻点 → 选「双击」（或三击）→ 滑到最下选 「截屏提取文字搜题」
3
完成后做题时：敲两下手机背面 → 系统自动截屏（无需手按）→ 系统实况文本识别 → 自动打开搜题平台 → 自动粘贴 → 自动搜题 → 自动弹出答案卡 ✓
✅ 全链路：敲两下 → 自动截屏 → 系统OCR提取 → 自动粘贴 → 自动搜题 → 自动显示答案，全程零手动。
首次数码：系统会询问"要打开 搜题平台 吗？"→ 选始终允许；搜题平台会询问"允许读取剪贴板吗？"→ 选允许（仅用于自动搜题）。

⚠️ 关于"不跳转、直接在原做题 App 里显示答案"

iOS 出于安全沙箱限制，任何普通 App 都不能在其他 App 之上显示内容（"考试宝"那种悬浮窗是越狱/TrollStore 或企业证书专属，App Store / 自签 App 都做不到）。 所以"不跳出原 App 直接看答案"在标准 iOS 上做不到；能做到的最顺滑方案就是上面的全自动跳转：敲两下 → 自动截屏 → 自动跳到搜题平台显示答案 → 看完按返回键回原 App（原 App 状态保留）。
这个快捷指令做的事（等价于手动配置）：
1. 截屏（Take Screenshot）
2. 打开 URL：searchbank://ocr-latest
前提：已安装搜题平台 v2.3+（图标为"100 考试"）。iOS 18 首次运行「打开 URL」会询问一次"允许打开此 App？"→ 选始终允许。
