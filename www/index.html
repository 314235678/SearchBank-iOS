本地文件夹保存（防浏览器清理）
选择本地文件夹后，题库会自动实时保存到该文件夹下的「搜题题库.json」，清理浏览器也不会丢。
· 支持 http://localhost 或 https 下打开本页面；
· 双击 file:// 打开或老版本浏览器不支持时，按钮会自动变为「下载 JSON 到本地」实现等价备份。
同一批 38 道真题实测：本地 OCR 四关全对 71%，AI 97%（带圈数字①②③、形近字、整块漏检、选项错位都明显更少），单题约 ¥0.0014、1.2 秒。
双引擎= 两个引擎各读一遍、逐行比对，结果以 AI 为准、本地当"监考老师"，发现分歧会在提示区列出来（耗时约翻倍，3~7 秒）。
注意：AI 模式会把题目截图上传到模型服务商，涉密或敏感材料请用「仅本地 OCR」。AI 失败（没配 Key / 断网 / 返回异常）时会自动回落到本地 OCR，不影响使用。
Umi-OCR 本地引擎：识别率最高、免费离线，需已安装 Umi-OCR（或设置环境变量 UMI_OCR_EXE 指向 PaddleOCR-json.exe）。识别结果自动进入搜索栏并搜题。
本地引擎：图片在浏览器内识别，不上传任何服务器；首次识别会联网下载约 5MB 识别引擎（之后浏览器缓存，离线可用），中文/英文均支持。
在线引擎：如 OCR.space 需科学上网；百度 OCR 需在百度智能云注册获取 API Key/Secret Key。
OCR 错别字纠错词典
